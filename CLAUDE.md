# Claude Code Bootstrap

Before doing any work in this repository:

1. Read the root `AGENTS.md` in full and treat it as the project-wide operating contract.
2. Read the active `.agents/work-items/*/state.yaml` file.
3. Read the `.agents/roles/*.md` file named by `current_role`.
4. Read all files listed in the work item's `spec_refs` before editing code or specifications.

Do not duplicate or override project rules in this file. If this file conflicts with `AGENTS.md`, follow `AGENTS.md` and report the conflict in the active work item.
